# RideConnect
A Ride Sharing App: A Database-Centric Perspective
RideConnect will offer a mobile application for both riders and drivers,
facilitating ride requests, driver-rider matching, it could be used for any
purpose, but we assume it will be Uber-Like experience, and will not be used
for order delivery (matching between driver and customer order) or any other
scenario. We will only focus on ride requests and acceptance, disregarding
payments, ratings, providing optimal routes, and sophisticated estimations
and recalculations of fare
